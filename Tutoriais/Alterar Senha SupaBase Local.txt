1. Localize a pasta do SupabaseSe você não sabe onde a pasta está instalada, use o comando de busca do Linux/Mac para encontrá-la:bashfind / -type d -name "supabase" 2>/dev/null
Use o código com cuidado.O terminal vai listar os caminhos encontrados. Geralmente o caminho termina em /supabase/docker.2. Navegue até a pasta corretaCopie o caminho encontrado no passo anterior e use o comando cd para entrar na pasta de configuração do Docker. Exemplo:bashcd /home/seu_usuario/supabase/docker
Use o código com cuidado.(Substitua pelo caminho exato que apareceu na sua tela).3. Abra e edite o arquivo de senhasAbra o arquivo de configuração .env usando o editor de texto integrado do terminal:bashnano .env
Use o código com cuidado.Use as setas do teclado para descer até encontrar as linhas de senha. Altere os valores após o sinal de igual (=):POSTGRES_PASSWORD=sua_nova_senha_do_bancoSTUDIO_DEFAULT_PASSWORD=sua_nova_senha_do_painelPara salvar e sair:Pressione Ctrl + O e aperte Enter para salvar.Pressione Ctrl + X para fechar o editor.4. Aplique as alterações no DockerReinicie os serviços do Supabase para que eles leiam o arquivo alterado:bashdocker compose down
Use o código com cuidado.bashdocker compose up -d
Use o código com cuidado.5. Sincronize a senha com o Banco de DadosPara evitar erros de conexão, você precisa atualizar a senha dentro do sistema do banco de dados rodando:Entre no terminal do banco de dados:bashdocker exec -it supabase-db psql -U postgres
Use o código com cuidado.Digite o comando abaixo (substitua pela mesma senha do banco que colocou no passo 3 e mantenha as aspas e o ponto e vírgula):sqlALTER USER postgres WITH PASSWORD 'sua_nova_senha_do_banco';
Use o código com cuidado.Saia do banco de dados:sql\q
