================================================================================
          ROTEIRO DE IMPLANTAÇÃO - GERADOR E CONTEXTO DO FISCAL WORKER
================================================================================

Este guia descreve o processo de geração e implantação do "fiscal-worker" no
ambiente do cliente. Como o processamento fiscal ocorrerá em um servidor central,
o worker rodará em uma única máquina (Servidor Windows da loja ou um PC caixa
designado) e processará a fila de notas fiscais de todos os outros terminais.

--------------------------------------------------------------------------------
PASSO 1: PREPARAÇÃO DOS ARQUIVOS NA SUA MÁQUINA DE DESENVOLVIMENTO
--------------------------------------------------------------------------------

1. Configuração do arquivo ".env" do Fiscal Worker:
   * Acesse a pasta "fiscal-worker" local.
   * Crie o arquivo ".env" baseado no ".env.example", preenchendo as chaves do 
     Supabase de Produção do cliente:
     
     SUPABASE_URL="https://seu-projeto.supabase.co"
     SUPABASE_SERVICE_ROLE_KEY="sua_chave_secreta_service_role"
     FISCAL_LIB_PATH="C:/Realcommerce/fiscal-worker/AcbrDLL/ACBrNFe64.dll"

     *Nota:* Use sempre a chave "service_role" no worker, pois ele roda no
     backend e precisa de permissões administrativas para atualizar registros.

2. Geração do Executável Único (Ocultando o Código-Fonte):
   Para evitar enviar o código JavaScript e a necessidade de instalar o Node.js 
   no servidor do cliente, compile o worker em um único arquivo ".exe":
   
   * No terminal, dentro da pasta "fiscal-worker", instale o "pkg" localmente ou
     execute diretamente via npx:
     npx pkg package.json --targets node20-win-x64 --output fiscal-worker
   
   * Isso gerará o arquivo "fiscal-worker.exe" na pasta.

3. Preparação da Pasta de Deploy:
   Crie uma pasta de deploy chamada "fiscal-worker-deploy" e copie para ela:
   * O arquivo executável "fiscal-worker.exe" gerado.
   * O arquivo ".env" configurado com as chaves de produção.
   * A pasta de DLLs "AcbrDLL/" contendo as DLLs de 64 bits do ACBr.
   * Os arquivos de configuração do ACBr (".ini") presentes na pasta.
   * O certificado digital do cliente (ex: "robe.pfx") se for do tipo A1.

--------------------------------------------------------------------------------
PASSO 2: IMPLANTAÇÃO NO SERVIDOR WINDOWS DO CLIENTE
--------------------------------------------------------------------------------

1. Copiar a pasta:
   * Transfira a pasta "fiscal-worker-deploy" para o servidor Windows local 
     do cliente (ex: salve em "C:\Realcommerce\fiscal-worker\").

2. Instalação e Teste Inicial:
   * Dê dois cliques em "fiscal-worker.exe". 
   * A janela do prompt de comando abrirá mostrando os logs de inicialização.
   * Faça uma nota de teste em qualquer caixa e confirme se o worker capturou,
     processou a nota via DLL e atualizou o status para "CONCLUIDO" no console.

--------------------------------------------------------------------------------
OPÇÃO RECOMENDADA: EXECUTAR COM TRAY E CONSOLE VISUAL (FiscalWorkerTray.exe)
--------------------------------------------------------------------------------

Para que o cliente final ou o administrador do servidor possa ver se o serviço 
fiscal está ativo de forma amigável, criamos um gerenciador visual que roda 
diretamente na bandeja do sistema (perto do relógio do Windows):

1. O que é o "FiscalWorkerTray.exe"?
   * Um executável desenvolvido em C# que encapsula e gerencia o "fiscal-worker.exe".
   * Ele inicia o processo do worker de forma oculta no Windows (sem abrir telas pretas de console) e captura todas as saídas de texto (logs).
   * Ele auto-reinicia o worker em 5 segundos caso o processo sofra alguma queda.

2. Como incluir no Deploy do Cliente:
   * Copie o arquivo "FiscalWorkerTray.exe" (gerado na raiz do projeto) e coloque 
     dentro da mesma pasta pai de "fiscal-worker/" no cliente.
     
     Estrutura de pastas no cliente:
     C:\Realcommerce\
       ├── FiscalWorkerTray.exe    <-- Colocar aqui
       └── fiscal-worker\
             ├── fiscal-worker.exe
             ├── .env
             ├── AcbrDLL\
             └── ...

3. Como usar no Cliente:
   * O administrador do servidor dá dois cliques em "FiscalWorkerTray.exe".
   * O aplicativo iniciará minimizado diretamente na bandeja (Tray) do Windows 
     com o ícone do sistema.
   * Dando dois cliques no ícone (ou clicando com o botão direito e selecionando 
     "Mostrar Logs"), abrirá uma janela com tema escuro elegante exibindo:
     - O status em tempo real com indicador luminoso (Verde para Rodando, Vermelho para Parado).
     - O histórico de logs detalhado mostrando cada emissão de nota.
     - Botões para "Limpar Logs" e "Reiniciar Serviço" manualmente.
   * Ao fechar a janela com o "X", o sistema não encerra; ele apenas se esconde 
     na bandeja para continuar monitorando as notas. Para fechar totalmente, clique 
     com o botão direito no ícone da bandeja e selecione "Sair".

4. Inicialização Automática com o Windows:
   * Para que o monitor de bandeja inicie sozinho ao ligar a máquina, basta criar
     um atalho para o "FiscalWorkerTray.exe" e colocá-lo na pasta "Inicializar"
     do Windows (atalho Win+R -> shell:startup).

--------------------------------------------------------------------------------
OPÇÃO ALTERNATIVA: EXECUTAR COMO SERVIÇO WINDOWS (SEM INTERFACE) VIA NSSM
--------------------------------------------------------------------------------

Caso prefira rodar como um serviço do sistema invisível (útil para servidores puros):

1. Baixe o nssm (nssm.cc) e extraia no servidor do cliente.
2. Abra o Prompt de Comando (CMD) como Administrador e execute:
   nssm install RealcommerceFiscalWorker
3. Na janela gráfica do NSSM que abrir:
   * Path: Selecione o "C:\Realcommerce\fiscal-worker\fiscal-worker.exe"
   * Startup directory: "C:\Realcommerce\fiscal-worker"
   * Clique em "Install service".
4. Abra o gerenciador de serviços do Windows (services.msc), localize o serviço
   "RealcommerceFiscalWorker" e configure como Automático (e clique em Iniciar).
